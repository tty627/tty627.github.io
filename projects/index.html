精选项目

Octopus

面向学习与研究的本地资料工作台。支持检索 PDF、Office、图片、文本和 ZIP，并定位到可核对的原文位置；可以整理证据、生成引用和导出研究资料包。

目前提供 Windows 开发预览版。

AI Airlock

面向 AI Agent 的本地上下文处理工具。在本地检测和处理敏感信息、可疑指令，筛选与任务相关的内容，并生成附带来源与审计记录的上下文。

Pintos

基于 Pintos 教学框架完成的双人操作系统课程项目。我的提交涉及可扩展文件系统、目录与块缓存实现，以及虚拟内存并发问题修复。

浦江实验室实习项目

大模型评测实习生 · 2026.08—2026.09。以下是这段实习中先后参与的两个项目。

项目一 · Rubric Pipeline

参与大模型评分标准生成与评测流程建设。将生成、冻结后实测、异源模型判分、区分度诊断和反馈修订拆分为可追踪的阶段，记录答案分歧与复核证据。

项目二 · Agent 指令遵循评测

基于 AgentCompass 与 Terminal-Bench 2.1 Verified，为任务加入过程约束，用多个模型检查难度与区分度，编写独立验证器，并结合运行轨迹、任务结果和约束判定形成评测结果。

Relay Model Auditor

保存 OpenAI 兼容端点的测试结果、证据哈希和历史记录，帮助整理与比较探索性证据；结果不能用于确认实际模型身份。

MatchUs

一个校园活动和临时组队的全栈应用原型，支持学校邮箱注册、活动发布与参与、签到、群聊、评价和举报。

crypto-quant

一个用 Python 写的加密货币永续合约回测项目，包含 Donchian 突破策略、多标的账户、参数搜索和图表输出。
