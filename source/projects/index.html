项目

这里列出我的公开仓库。点击项目名称可以查看代码和完整说明。

Octopus

面向学习和研究的 Windows 本地资料工具。它能搜索 PDF、Office、图片、文本和 ZIP，并把结果定位到原文位置，方便核对和整理引用。

Relay Model Auditor

一个用于检查 OpenAI 兼容 API 的本地工具。它会保存测试结果和历史记录，帮助比较不同端点；现阶段不能仅凭结果断定实际模型身份。

Trajectory Workspace Plugin

给 DeepSeek Harness Web 增加一个轨迹面板，可以停靠在页面左右两侧，也可以作为浮动窗口使用，并记住每个会话的布局。

DSH Trajectory Control

一组面向 DeepSeek Harness 的设计文档和代码补丁，目前可以从轨迹中的某一步创建分支、加入新指令并继续运行。

Pintos

参与完成的操作系统课程项目，内容包括线程调度、系统调用、虚拟内存和文件系统。

crypto-quant

一个用 Python 写的加密货币永续合约回测项目，包含 Donchian 突破策略、多标的账户、参数搜索和图表输出。

MatchUs

一个校园活动和临时组队的全栈应用原型，支持学校邮箱注册、活动发布与参与、签到、群聊、评价和举报。

CS100 Tank

一个用 C 和 ANSI 终端渲染的坦克游戏课程作品，包含随机地图、可破坏墙体、敌方 AI 和生命、热量系统。

CS100 Zombie

基于课程 PvZ 框架完成的反向玩法作业：玩家投放僵尸、使用阳光，逐关突破植物防线。运行时需要原课程工程模板。

tty627.github.io

这个个人网站的源代码，使用 Hexo 和 Fluid 组织页面，并通过 GitHub Actions 自动部署到 GitHub Pages。

llm-fingerprint-detector（Fork）

从 ToseaAI 项目 fork 的 TypeScript 库和命令行工具，用单 token 输出分布比较 OpenAI 兼容端点。结果只能作为探索性参考，不能单独确认模型身份。
