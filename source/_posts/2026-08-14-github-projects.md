## crypto-quant

一个用于加密货币永续合约回测的 Python 项目，核心是突破策略（Breakout）与参数优化。

- Donchian Breakout + 趋势过滤回测
- 多标的统一资金账户回测
- 参数网格优化与自动搜索
- Plotly 可视化输出（权益曲线、热力图等）
- GitHub Actions CI 与跨平台 Release（macOS / Windows / Linux）

> 仓库地址：<https://github.com/tty627/crypto-quant>，详细使用方式见 [crypto-quant 介绍](/2026/08/14/crypto-quant/)

## MatchUs

一个面向上海科技大学学生的校园社交网络应用，支持发布活动、寻找搭子/小圈子，并通过独特的「实名延迟揭示机制」，在保证安全的前提下建立真实可信的连接。技术栈包括 bcrypt 密码哈希、JWT 身份认证、邮箱验证注册等。

> 仓库地址：<https://github.com/tty627/MatchUs>

## octopus

Octopus 是一个本地优先（local-first）、以链接为中心（link-centric）的文件索引 CLI，用 Python 编写。

> 仓库地址：<https://github.com/tty627/octopus>

## pintos

> 仓库地址：<https://github.com/tty627/pintos>
